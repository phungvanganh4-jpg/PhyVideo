## 渲染指南（在你自己的电脑上）

### 1. 准备环境

| 需要 | 说明 |
|---|---|
| **Node.js 18 或更新** | <https://nodejs.org> 下载 LTS 版，安装后在终端运行 `node -v` 确认 |
| **Git** | 用来下载本仓库（也可以在 GitHub 页面点 *Code → Download ZIP*） |
| **ffmpeg**（可选） | 装了就用系统的；没装会自动用 npm 里的 `ffmpeg-static` |
| 磁盘 | 约 2 GB（依赖 + 浏览器 + 中间文件） |

Windows / macOS / Linux 都可以，下面的命令在 Windows 的 PowerShell 或 cmd 里也一样能用。

### 2. 下载并安装依赖

```bash
git clone https://github.com/phungvanganh4-jpg/phyvideo.git
```

```bash
cd phyvideo
```

```bash
npm install
```

`npm install` 会顺带自动下载渲染用的 Chromium 浏览器（约 150 MB）。如果这一步下载浏览器失败，可以单独再运行：

```bash
npx playwright install chromium
```

### 3. 先试渲染几秒（强烈建议）

```bash
node render-all.js --ep 1 --seconds 12 --gpu
```

成功后会生成 `final/原子的精细结构_第1集_全景与轨道磁矩.mp4`（只有 12 秒），打开看看画面、文字、音乐是否正常。

> **`--gpu` 是什么？** 用你电脑的显卡渲染 3D，比纯软件渲染快很多（通常 5–10 倍）。
> 如果加了 `--gpu` 后画面全黑、报错或卡死，就去掉 `--gpu`，改用软件渲染（慢，但任何电脑都能跑）。

### 4. 渲染全部六集

```bash
node render-all.js --gpu
```

成片输出到 `final/` 文件夹，每完成一集就会生成一个 mp4，终端里会实时显示进度和预计剩余时间。

常用参数：

| 参数 | 作用 | 默认 |
|---|---|---|
| `--ep 2,5` | 只渲染指定的集 | 1,2,3,4,5,6 |
| `--gpu` | 用显卡渲染（推荐） | 关 |
| `--workers 4` | 并行开几个浏览器，一般设为 CPU 核数的一半左右 | 3 |
| `--fps 30` | 帧率 | 24 |
| `--crf 16` | 画质（数字越小越清晰、文件越大，18 已接近无损观感） | 18 |
| `--noaa` | 关闭抗锯齿（更快，但细线会有锯齿） | 开抗锯齿 |
| `--seconds 12` | 只渲前 N 秒，用于试渲染 | 整集 |

### 5. 大概要多久

全片约 30 分钟 × 24 帧 ≈ 43,000 帧。

- **用显卡（`--gpu`）**：中等配置的电脑大约 0.03–0.08 秒/帧/进程，6 集共约 **20–60 分钟**。
- **软件渲染（不加 `--gpu`）**：约 0.25 秒/帧/进程，3 路并行时 6 集共约 **1–1.5 小时**。

可以只渲某一集（`--ep 3`），中断后重新运行即可，已完成的集保存在 `final/` 里不会丢。

### 6. 只看几张截图（调试用）

```bash
node render-all.js --preview --ep 4 --times 3,60,200
```

截图保存在 `preview/`。注意这里的时间是**脚本时间**（剧本时间轴，未经节奏压缩），与成片时间不同。

## 常见问题

- **画面里汉字显示成方块 / 字体不对**：字体全部来自 `node_modules/@fontsource`，请确认 `npm install` 成功完成，不需要在系统里安装字体。
- **`Timeout ... window.READY`**：第一次加载字体较慢，再运行一次即可；若一直这样，请去掉 `--gpu` 试试。
- **`ffmpeg` 相关报错**：安装系统 ffmpeg（Windows 可用 `winget install ffmpeg`，macOS 可用 `brew install ffmpeg`），或者设置环境变量 `FFMPEG=ffmpeg 的完整路径`。
- **想换配乐**：替换 `assets/music/fate.mp3` 即可（每集都从音乐开头开始，片头文字卡点在前 4 秒的“命运动机”上）。
- **中文文件名乱码（Windows）**：不影响视频本身，可在资源管理器里直接重命名。

## 工程结构

| 文件 | 作用 |
|---|---|
| `ep.html` | 页面与全部 CSS（暗黑配色、字体、卡片样式） |
| `engine.js` | 公共引擎：渲染器、调色板、箭头/锥/能级图/矢量模型、3D 卡片面板、3B1B 式公式变形 `deriv`、镜头系统（含倾斜、甩镜转场、样条路径）、节奏压缩（time-warp） |
| `noir.js` | 视觉组件：等高线能量地形、黑洞式网格漏斗与旋流粒子、3D 动态打字 `KText`、弧形文字、等宽数值标签、卡点片头与片尾 |
| `ep1.js` … `ep6.js` | 每集的剧本：场景、卡片、推导、镜头、时间轴 |
| `render-all.js` | 一键渲染：内置静态服务器 → 多进程逐帧截图 → ffmpeg 编码 → 拼接 → 配乐 |
| `assets/music/fate.mp3` | 贝多芬《第五交响曲》第一乐章，Internet Archive 公有领域录音（Musopen 标注） |
| `docs/STYLE_NOIR.md` | 视觉风格与组件用法说明（改剧本时参考） |

### 修改内容后怎么看效果

1. 改 `epN.js` 里的卡片文字、时间或镜头。
2. 用 `--preview` 截几张图检查（时间单位是剧本时间）。
3. 满意后 `node render-all.js --ep N --gpu` 重新渲染这一集。
